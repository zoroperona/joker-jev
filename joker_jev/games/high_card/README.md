# 双人三轮比牌

用于验证多游戏协议的小型示例，不对应斗地主或扑克的完整规则。

- 牌堆：1 到 8，各一张。每人随机发 3 张，剩余 2 张暗置不用。
- 玩家：p0、p1。p0 首轮先出，另一方看到出牌后行动。
- 每轮双方各出一张，大牌获胜，赢家下一轮先手。
- 赢一轮奖励 +1，输一轮 -1；只有先手出牌时双方奖励为 0。
- 三轮结束，无额外终局奖励；累计奖励范围为 -3 到 +3。
- 手牌对对手隐藏；牌堆构成、出牌、剩余牌数、比分公开。

运行时规则见 `HighCardGame.rules`，这是传给 JEV 的规则来源；规则变更时同步更新本文和测试。

记牌器统计公开已出牌，排除自己的剩余手牌，得到未知牌集合。猜牌采用均匀分配假设：某张未知牌在对手手中的边际概率 = 对手剩余牌数 / 未知牌数。未知牌还包含暗置牌，不能全当作对手手牌。这一估计忽略对手的策略性出牌，因此不是经过行为更新的精确后验。

启发式基线后手选择最小可赢牌，无法赢则出最小牌；先手出最大牌。该策略仅用于测试，不保证最优。CLI 默认使用通用随机策略。
