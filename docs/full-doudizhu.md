# 完整斗地主规则与实现

本项目的主游戏 `doudizhu` 采用三人、54 张、叫分制经典斗地主，从发牌运行到计分。原来的 1–4 张受限残局仍保留为独立的战术实验，不再代表主游戏能力范围。

## 发牌与叫地主

- 普通牌 3 至 2，每点四张；小王 SJ、大王 BJ 各一张。花色不参与牌型比较。
- 三个固定座位 p0/p1/p2，每人 17 张，留下 3 张底牌。按座位顺序行动，首叫者随发牌种子变化。
- 每人最多叫一次 0/1/2/3 分。0 为不叫，非零必须高于当前最高分；叫 3 分立即成为地主，否则三家叫完后最高者成为地主。
- 三家都不叫则重新洗牌发牌并轮换首叫者，可连续重发；不强制指定地主。实验步数上限仍作为运行错误单列。
- 确定地主后公开底牌并归地主，形成 20/17/17 张。地主先出；两名农民共享胜负。
- 这是叫分制，不额外启用抢地主、明牌、加倍/超级加倍、癞子或四人变体。

## 牌型与地区规则取舍

点数次序：3 < 4 < … < A < 2 < 小王 < 大王。

| 牌型 | 规则 |
|---|---|
| 单张、对子、三张 | 同点数 1、2、3 张 |
| 三带一 / 三带一对 | 三张加一个不同点数的单张或对子 |
| 顺子 | 至少 5 个连续点数，各一张 |
| 连对 | 至少 3 个连续点数，各两张 |
| 飞机 | 至少 2 个连续点数，各三张 |
| 飞机带单翅 | k 组三张 + k 张翅膀；单翅可组成对子，但每点最多两张，且不能同时带双王 |
| 飞机带对翅 | k 组三张 + k 个不同点数的对子 |
| 四带二单 | 四张 + 两张单牌，允许这两张组成对子；不能同时带双王 |
| 四带二对 | 四张 + 两个不同点数的对子 |
| 炸弹 | 同点四张 |
| 王炸 | 小王 + 大王 |

连续主体都只能包含 3 至 A，不能含 2 或王。翅膀不得使用主体点数的第四张。上述单翅和四带二的取舍是本仓库的明确约定；不同平台可能采用其他规则，本版本不声称兼容所有地区变体。

普通接牌必须同类型、同张数、同连续长度，按主体最大点数比较；附带牌不参与大小比较。炸弹可压所有普通牌型，较大炸弹可压较小炸弹；王炸可压其他一切牌型。四带二、飞机带翅膀中的四张不算炸弹。

自由领出必须出牌。其他玩家可出更大牌或过牌；连续两人过牌，上次出牌者恢复自由领出。任一家手牌为空立即结束，不再让其他玩家行动。

## 奖励与积分

底分是最终叫分。每打出一个独立炸弹或王炸，倍数乘 2。地主获胜且两位农民均未成功出牌为春天；农民获胜且地主只成功出牌一次为反春天；两者均额外乘 2。过牌不计成功出牌次数。

设 `unit = 叫分 × 2^(炸弹及王炸次数 + 春天标志)`：地主赢得 `2 × unit`、每位农民失去 `unit`；农民赢时相反。积分总和为零，农民两人积分相等。报告另存团队胜负 ±1，把赢输和积分分开；接口失败或回合上限没有胜负和积分。

## 简单 AI

`full/agents.py` 的 `FullSimpleAgent` 独立完成叫地主和所有牌型出牌：根据王、2、炸弹和近似手牌组合数叫分；出牌优先直接出完，结合队友让牌、敌方报单拦截、对子或复合牌压制、保炸弹及粗略剩余组合数选牌。实现为原创启发式，没有训练权重和外部依赖，不读对手底牌，也不调用模型。不是最优解。

## JEV 与信息隔离

JEV 只收到自身手牌、已确定身份、公开叫分/出牌历史、剩余牌数、公开底牌、规则及奖惩。叫地主结束前底牌不可见。推断用完整牌堆减去自己手牌和已出牌，底牌用于约束地主剩余牌的已知下界；其他未知牌按剩余容量均匀估计，不把过牌等同于没有大牌。

当前命令行默认 `v2_compact`，在以下基础适配之上增加拆牌与动作后果摘要，最终动作每组最多 24 项，必要时继续按附件分组选择。可用 `--strategy v1` 恢复原版；新版对照和限制见 [策略调整](strategy-adjustment.md)。

原版 最多 255 个动作时直接 Choice。超过时先按牌型选择，如果仍超过，再按主体点数与长度选择，最后选择具体翅膀/动作。每个合法动作都保留可达路径，不通过截取前 255 个来丢弃候选。分层结构会影响决策，不能视作与一次性全候选判断完全等价。模型返回概率是选择判断，不是校准胜率。

游戏状态内部的洗牌种子、所有手牌和未公开底牌不传给 Agent。完整研究日志保存各玩家轮到自己时的私有视角，用于复盘；日志不回灌给其他玩家，对外发布纯公开回放应使用 `public_history`。

## 运行与测试

```bash
# 通用 CardGame 引擎运行完整斗地主
python3 -m joker_jev --game doudizhu --agent simple --seed 42
# 十场本地完整自对弈，保存结果和逐步日志
python3 -m joker_jev.games.doudizhu.full.match --episodes 10 --output reports/full-local-new.json
# 十场完整 JEV 对简单 AI，模型固定；需要 .env
python3 -m joker_jev.games.doudizhu.full.match --live --episodes 10 --seed 20261016 --output reports/full-live-new.json
python3 -m unittest discover -s tests -v
```

JEV 每场控制一个轮换的固定座位（p0/p1/p2），是否成为地主由本场叫分决定；其他两个座位由简单 AI 控制。牌局种子、目标座位和首次发牌在请求前冻结；全不叫重发仍由同一固定种子序列决定。不同策略可能导致不同叫分或重发，因此相同初始种子不保证后续地主和底牌分配一致。

测试覆盖所有牌型、独立子集穷举的生成完整性、叫分/重发/底牌公开时机、两次过牌、牌数守恒、自然终局、春天与反春天、炸弹与王炸积分、零和奖励、未知牌估计、分层候选限制、错误保留及旧残局回归。胜率和人工偏好不作为正确性测试门槛。
